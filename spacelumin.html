01 / Scope

System and contribution

End-to-end software architecture and verification.

The core engineering goal: observe high-frequency runtime telemetry, predict the next discrete state in real time, and score those predictions online without mutating or slowing down the active application loop.

I designed and implemented the gameplay systems, telemetry pipeline, Markov prediction model, runtime overlay, leakage-safe evaluation system, deterministic tests, and supporting PWA tooling.

01

Encode behaviour

Continuous runtime signals are reduced to discrete states so transition counts can be updated and queried in O(1) without blocking the render loop.

02

Predict next state

The Markov transition model estimates the most probable next encoded state from observed transitions with online probability updates.

03

Deduplicate frames

A state-epoch guard prevents 60Hz render frames from counting the same state transition multiple times.

04

Prevent leakage

Predictions are frozen prior to outcome resolution; the evaluator receives completed events through a read-only adapter boundary.

05

Separate modes

Frozen-model and prequential online-learning modes remain strictly separated so runtime metrics stay reproducible.

03 / Evaluation design

Verification without data leakage

16/16 deterministic tests
Mode A

Frozen evaluation

Evaluates a fixed transition matrix so prediction accuracy can be measured without online updates shifting the baseline mid-session.

Mode B

Prequential evaluation

Follows strict test-then-train ordering: predicts first, observes the completed state transition, scores the event, and only then updates transition counts.
